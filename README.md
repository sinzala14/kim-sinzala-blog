# Kim Sinzala — personal blog & portfolio
Vanilla HTML/CSS/JS + Node/Express. Run: `npm install && npm start` → http://localhost:3000

- Posts: `data/posts.json` (blocks: `p`, `h`, `code`). Sample posts are marked SAMPLE DRAFT.
- Projects: `data/projects.json` (`kind` = FACT / EXPERIMENT / ASPIRATION).
- Skill tiers and hover notes: top of `public/js/main.js`. Adjust to what is true.
- Replace `public/assets/profile-placeholder.jpg`, the `YEAR`/`YOUR_EMAIL` placeholders and `SITE_URL` (env var).
- Future: swap `readJSON` in `server.js` for PostgreSQL queries; add admin/auth later.
